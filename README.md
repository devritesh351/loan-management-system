# Loan Management Frontend

Modern fintech-inspired loan management system frontend built using:
- React
- TypeScript
- Tailwind CSS
- Vite

Features:
- Borrower dashboard
- Admin dashboard
- Fallback offline mode
- Responsive UI

Backend microservices using Spring Boot are under development.
